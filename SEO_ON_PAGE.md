# On-page SEO — phase 3

The build now applies ten unique Dutch titles and descriptions, Open Graph and
Twitter card metadata, and JSON-LD with Organization, WebSite, WebPage (or a
more specific page type) and BreadcrumbList on subpages. Facts are taken from
the existing website. No invented reviews, hours, registrations or social
profiles. All metadata uses the same canonical URLs as phase 2.

The existing logo is reused to generate a square 96px PNG favicon, a 512px
organization logo and a 1200x630 JPEG social card. The favicon is explicitly
linked from every generated page. White padding keeps the wide logo intact.
The shared social card avoids attributing unverified imagery to the business.

Content: preserve existing H1 slogan and visible headings, promote service and
contact subheadings semantically with equivalent CSS, populate the empty
clients heading from the existing NL translation, improve generic alt labels
without inventing image details, and link the gallery from the existing footer
label and breadcrumb trail. Search homepage links point to / instead of the
redirected index.html. Gallery stock photo captions remain unchanged pending
authentic company photos/approval. Image-specific alt descriptions require
visual review; existing staff and partner names remain unchanged.

The static SEO metadata and alt text are Dutch, matching the initial document
language. Separate English/Spanish URLs, translated metadata and alt labels,
and hreflang are reserved for phase 4; the current JS language switch stays intact.
All transformations are applied to built output; source HTML remains unchanged.
No contact API, security, DNS, domain, sitemap or routing changes. Review visual
parity, title/snippet copy, favicon legibility, gallery links and contact form.
