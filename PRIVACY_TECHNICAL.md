# Privacy phase 2 — local assets and automatic maps

- Fontsource packages pinned to Cormorant Garamond 5.1.0 and Source Sans 3 5.2.6. Existing font families, weights, font-display and Unicode ranges retained. Build copies font binaries and OFL licenses; content-addressed CSS/fonts use existing immutable cache headers. The pinned releases may differ from the live Google Fonts version; inspect rendering.
- The 12 distinct existing Unsplash CDN URLs (13 image references per language) are downloaded only at build time. They are validated, limited in size, compressed when beneficial, and served from fingerprinted first-party URLs. One pre-existing gallery URL returned HTTP 404 in the first preview build; it is replaced by the existing local homepage flower photo (foto 5.jpeg) with an accurate translated caption. Build fails if remaining downloads fail; no external fallback. This deliberately does not introduce a runtime proxy. Build depends on network availability; preferred follow-up is to vendor approved image files with provenance and hashes.
- Copyright license: https://unsplash.com/license. Third-party model/property/trademark rights and the status of each original photo must still be confirmed before merge. Existing stock photos are not newly claimed to be authentic; original visible captions are retained for review. https://help.unsplash.com/en/articles/2612329-releases-and-trademarks
- Maps: retain original automatic Google Maps iframes on 9 localized pages, including native lazy loading. No consent placeholder or map-consent storage. This is an explicit product decision. Google can receive visitor data and may store or access device information before consent; assess the actual browser behavior, lawful basis and consent requirements before production release. Disclosure alone does not replace legally required consent. No general cookie banner added in this PR.
- Remove old language localStorage reads and writes; the URL remains authoritative, source-mode fallback uses document language. Do not clear any unrelated visitor data. Existing old language keys are inert.
- Contact API, Turnstile, Resend, SEO and subscriptions unchanged. Browser tests for maps, search, contact, typography and storage remain necessary before release. No claim of full AVG compliance.
